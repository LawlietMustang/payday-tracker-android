# WageTrack 2.4.0

Applies the supplied purple, lime and cream app design to the existing Android app.

- Dashboard: available income estimate, next shift, base pay/bonus bar and recorded payslip comparison. The available amount is all-workplace estimated net less personal monthly expenses; savings balances are not silently deducted.
- Monday-first shift calendar with real planned/completed/active/overlap states, month navigation, day details, shift editing and saved-template shortcuts. Existing list and batch selection remain available.
- Savings goal rings and consistent budget, settings, reminder, onboarding and dialog styles in both appearances.
- Floating navigation and matched native system bars; no remote assets required.
- Existing payroll formulas, storage format, application ID and permanent signing configuration retained. This release does not change notification delivery or Google account configuration.

Validation: existing browser and Android smoke workflows plus calendar interactions, financial summary consistency, savings progress, empty states, both languages/themes and responsive screenshots.
